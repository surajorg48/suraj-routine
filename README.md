# Suraj Aesthetic Transformation Hub

A mobile-first, offline-capable web application and gym logger for the **6-Month Aesthetic Transformation Program (Men's Physique Standard)**.

## Features
- **6-Day Split with Interactive Logger**: Track working weights (kg), reps, and check off sets in real-time.
- **Accurate Form Tutorials**: Direct YouTube search queries targeting the exact muscle group and bodybuilding technique.
- **Floating Gym Rest Timer**: Quick presets (30s, 60s, 90s, 2m, 2.5m, 3m) with offline sound chime & phone vibration.
- **Daily 130g Protein Tracker**: Indian food cost-per-gram value table, sample meal plan, and 5 belly fat rules.
- **24-Week Progression & Deload Tracking**: Built-in 40% deload alerts for Weeks 6, 12, 18, and 24.
- **Offline Gym Database**: Saves automatically to `LocalStorage`. Includes one-click JSON backup export and import.
- **PWA & Mobile Ready**: Add to Home Screen on iOS and Android for a native app feel.
