Section 1 — Understand the Terminology

| Read this before your first session. Misunderstanding these terms = misusing the program. |
| --- |

| TERM | MEANING |
| --- | --- |
| REP | One complete movement. Lower bar to chest, press up = 1 rep. Do 8 = "8 reps". |
| SET | A group of reps without stopping. "4 × 8" = 4 sets of 8 reps. |
| WORKING SET | Real sets with target weight. These build muscle. Every rep counts. |
| WARM-UP SET | Light sets before working sets. Prepare joints and CNS. Never count toward volume. |
| RIR 0 | Absolute failure — cannot do one more clean rep. Last set of isolation only. |
| RIR 1 | Could do 1 more if forced. Most isolation working sets. |
| RIR 2 | Could do 2 more. All compound working sets. |
| TEMPO 3-1-1-0 | 3 sec lower → 1 sec pause → 1 sec lift → 0 pause at top. |
| PROGRESSIVE OVERLOAD | Systematically increasing weight over time. Without this, muscles stop growing. |
